# SketchUp Plugins — Εκπαιδευτικό υλικό για το γραφείο (2026)

Τεκμηριωμένο, διασταυρωμένο υλικό για εσωτερική εκπαίδευση αρχιτεκτόνων στα plugins του SketchUp,
και έτοιμο σενάριο podcast 30 λεπτών για το **NotebookLM**.

## Αρχεία
- **`01-knowledge-base.md`** — Η βάση γνώσης: επαληθευμένα facts (τιμές, εκδόσεις, συμβατότητες,
  ρίσκα) με σημειώσεις πηγών. Ανέβασέ το ως source στο NotebookLM.
- **`02-podcast-script-30min.md`** — Οδηγίες χρήσης NotebookLM + steering prompt + πλήρες σενάριο
  διαλόγου δύο παρουσιαστών (~30’) στα ελληνικά.

## Γρήγορη χρήση
1. Νέο Notebook στο NotebookLM → ανέβασε **και τα δύο** `.md` ως sources.
2. Audio Overview → Customize → κόλλησε το steering prompt από το `02-...md` (Μέρος 1).
3. Output language: Ελληνικά → Generate.

## Σύνοψη συστάσεων
- **Minimum (Day 1, δωρεάν):** TT_Lib² → CleanUp³ → Solid Inspector²
- **Recommended:** + Profile Builder 4, FlexTools Pro, ένας renderer (D5/Enscape/V-Ray), Architextures
- **Advanced:** + Joint Push Pull/Curviloft, Skatter 2, PlaceMaker, Skimp, Quantifier Pro, Artisan 2
- **Προσοχή/legacy:** 1001bit Tools (test before use), licensing Fredo6, αποφυγή plugins που
  διπλασιάζουν native (Solid Tools, Sandbox, Section Fills).
