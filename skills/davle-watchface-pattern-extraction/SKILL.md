# DAVLE Watch Face Pattern Extraction

## Objective
Turn market evidence into reusable design primitives without copying any one competitor.

## Extract patterns across
- time presentation and hierarchy,
- analog/digital/hybrid structure,
- dial zoning and information density,
- complications and data placement,
- typography,
- numerals and indices,
- hand geometry,
- palettes and accent behavior,
- textures, depth, glow, borders, rings, grids,
- AOD simplification,
- customization surfaces,
- store-preview visual hooks.

## Workflow
1. Compare the market set across dimensions above.
2. Count recurrence where possible.
3. Distinguish structural patterns from superficial styling.
4. Identify combinations that recur together.
5. Identify contradictions: features that appeal to different segments and should not be mixed casually.
6. Convert findings into atomic design rules.

## Rules
- Do not copy distinctive protected artwork, logos, trade dress, or a single product's unique composition.
- Prefer cross-product abstractions.
- Label each pattern as evidence-backed, plausible, or speculative.

## Output
Return a pattern matrix with:
- pattern,
- evidence strength,
- likely commercial role,
- compatibility notes,
- saturation risk,
- recommended use / avoid guidance.

End with a compact handoff to `davle-commercial-dial-synthesis`.
