# DAVLE Commercial Dial Synthesis

## Objective
Create one original dial concept with a clear commercial rationale from upstream evidence.

## Workflow
1. Read the latest market, trend, and pattern handoffs.
2. Define target buyer and use context in one sentence.
3. Select only mutually compatible winning patterns.
4. Choose a primary visual hook that is recognizable at thumbnail size.
5. Set hierarchy: time first, supporting data second, decorative depth third.
6. Define style, layout, palette logic, typography class, information density, complications, and AOD concept.
7. Add one or two distinctive DAVLE elements so the concept is not a market-average collage.
8. State which popular patterns were intentionally excluded and why.

## Commercial scoring
Score 1-5:
- immediate readability,
- thumbnail impact,
- premium perception,
- broad appeal,
- differentiation,
- customization potential,
- implementation realism.

Reject concepts with average score below 3.5 or readability below 4.

## Rules
- Do not reproduce a competitor's distinctive composition.
- Do not combine every popular feature; coherence beats feature count.
- Prefer one strong commercial thesis over several weak directions.
- If evidence points to multiple incompatible segments, choose one.

## Output
Return:
- concept name,
- target buyer,
- commercial thesis,
- exact dial architecture,
- visual hook,
- palette logic,
- typography/indices/hands guidance,
- data/complication plan,
- AOD direction,
- scoring,
- handoff to `davle-dial-prompt-engineering`.
