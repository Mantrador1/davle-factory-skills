# DAVLE Watch Face Portfolio Intelligence

## Objective
Ensure the next DAVLE concept strengthens the portfolio instead of becoming another version of something DAVLE already has.

## Inputs
Use the current DAVLE portfolio registry when available. Distinguish:
- released products,
- production-ready products,
- active concepts,
- abandoned experiments.

Do not invent portfolio entries when the registry is incomplete.

## Compare each candidate on
- analog / digital / hybrid class,
- style/category,
- target user,
- dominant layout,
- primary visual hook,
- information density,
- complication strategy,
- color family,
- typography direction,
- premium level,
- practical use case,
- store-thumbnail appearance.

## Portfolio metrics
Rate 0–5:
- novelty versus current DAVLE portfolio,
- category whitespace fit,
- cannibalization risk,
- visual distinctiveness at store-thumbnail size,
- ability to extend the DAVLE brand without becoming repetitive.

## Rules
- Do not reject a strong market category merely because DAVLE already has one product in it.
- Reject near-duplicates whose main difference is color or superficial decoration unless there is a clear commercial reason.
- Prefer meaningful portfolio whitespace when market evidence for that whitespace is credible.
- Preserve useful brand coherence without forcing every face into one aesthetic template.
- Never let portfolio diversification override strong negative market evidence.

## Output
Return:
- nearest DAVLE portfolio neighbors,
- cannibalization risk: LOW / MEDIUM / HIGH,
- whitespace opportunity,
- portfolio-fit score,
- KEEP / MODIFY / REPLACE recommendation,
- specific modifications if needed,
- handoff to commercial synthesis or opportunity scoring.

## Missing-registry behavior
If no reliable portfolio registry is available, state that portfolio intelligence is limited and do not fabricate a diversification conclusion.
