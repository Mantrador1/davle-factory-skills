# Πρόσβαση στο εργοστάσιο από παντού

Το πρόβλημα της 26/07/2026: όταν χάλασε το laptop, χάθηκε **ο μόνος** τρόπος
πρόσβασης στον σέρβερ. Το κλειδί SSH, οι σημειώσεις και το Claude Code ήταν
όλα στο ίδιο μηχάνημα.

Αυτός ο φάκελος το διορθώνει. Στόχος: **καμία συσκευή να μην είναι
απαραίτητη.**

---

## Φάση 0 — Αντίγραφο του κλειδιού (κάν' το πρώτο)

Το υπάρχον κλειδί υπάρχει μόνο στο laptop. Αν χαθεί το laptop, χάνεται.

Στο **laptop**:

```bash
cat ~/.ssh/id_ed25519        # ή id_rsa
```

Αντίγραψε το κείμενο σε:

1. **Password manager** (Bitwarden, 1Password, KeePass) — το κύριο αντίγραφο
2. **USB stick** σε συρτάρι — το offline αντίγραφο

⚠️ Ποτέ σε email, Google Drive χωρίς κρυπτογράφηση, ή chat.

---

## Φάση 1 — Δεύτερο κλειδί από το κινητό

Ένα κλειδί = ένα σημείο αποτυχίας. Το κινητό γίνεται ανεξάρτητος δρόμος.

**Στο Termius (κινητό):** Settings → Keychain → **+** → Generate key →
τύπος **Ed25519** → όνομα `phone-termius` → αντίγραψε το **public key**.

**Στον σέρβερ** (από το laptop, με SSH):

```bash
cd /opt/factory
git pull
bash resilience/add_backup_key.sh "ssh-ed25519 AAAA... phone-termius"
```

⚠️ **Δοκίμασε τη σύνδεση από το κινητό ΠΡΙΝ κλείσεις το τερματικό του
laptop.** Αν κάτι πήγε στραβά, θέλεις ανοιχτή την πόρτα για να το διορθώσεις.

---

## Φάση 2 — Τα κλειδιά στο Hetzner Robot

Το Robot κρατάει public keys και τα περνάει στο **rescue system**. Αν ποτέ
χρειαστεί rescue, θα μπαίνεις με κλειδί αντί για κωδικούς email.

Robot → **Key management** → Add key → επικόλλησε **και τα δύο** public keys
(laptop και κινητό).

---

## Φάση 3 — Το Claude μόνιμα μέσα στο εργοστάσιο

Αυτό είναι το κομμάτι που λύνει το «δουλειά από το κινητό». Το
`claude remote-control` τρέχει ως υπηρεσία systemd: ξεκινά σε κάθε boot και
επανεκκινεί μόνο του αν πέσει.

**Προαπαιτούμενο** — ο `deploy` πρέπει να είναι συνδεδεμένος με λογαριασμό
claude.ai (όχι API key):

```bash
sudo -u deploy -i claude auth login
```

Μετά:

```bash
cd /opt/factory
sudo bash resilience/setup_remote_control.sh
```

Το script βρίσκει μόνο του το `claude`, στήνει την υπηρεσία, την ενεργοποιεί
στο boot και επιβεβαιώνει ότι σηκώθηκε.

Έλεγχος και λογs:

```bash
systemctl status claude-remote-control --no-pager
journalctl -u claude-remote-control -n 50 --no-pager
```

## Φάση 4 — Επαλήθευση από το κινητό

1. Claude app → **Code**
2. Πρέπει να υπάρχει session **Factory** με εικονίδιο υπολογιστή και
   **πράσινη κουκκίδα**
3. Άνοιξέ το και ζήτα κάτι απλό, π.χ. `systemctl status factory-panel-mvp`

Αν απαντήσει, τελείωσε: **το εργοστάσιο είναι προσβάσιμο χωρίς laptop.**

---

## Φάση 5 — Ο κώδικας εκτός σέρβερ (προαιρετικό, αλλά συνιστάται)

Αυτή τη στιγμή το `/opt/factory/` υπάρχει **μόνο** στον σέρβερ.

⚠️ **ΚΡΙΣΙΜΟ:** το `/opt/factory/secrets/` περιέχει API keys (OpenAI,
Ideogram) και τον κωδικό sudo. Αν ανέβουν στο GitHub, διαρρέουν. Πριν από
οποιοδήποτε `git add`:

```bash
cd /opt/factory
cat > .gitignore <<'EOF'
secrets/
evidence/
*.log
*.key
*_api_key*
*password*
EOF

git init
git add .gitignore
git status          # ΔΙΑΒΑΣΕ τη λίστα πριν προχωρήσεις
```

Έλεγξε ότι **κανένα** αρχείο από το `secrets/` δεν εμφανίζεται. Μετά:

```bash
git add .
git commit -m "Initial factory snapshot"
```

Το remote να είναι **private** repo. Ποτέ public.

## Κάρτα έκτακτης ανάγκης

Αν ξαναχαθεί μια συσκευή, η σειρά είναι:

| # | Δρόμος | Απαιτεί |
|---|--------|---------|
| 1 | **Claude app → Code → Factory** | τίποτα, αν τρέχει η υπηρεσία |
| 2 | **Termius από κινητό** | το κλειδί `phone-termius` |
| 3 | **SSH από άλλο PC** | το κλειδί από τον password manager |
| 4 | **Robot → Support → Remote Console** | κωδικό `deploy` (ζήτα **3 ώρες**) |

Χρήσιμα στοιχεία:

- Σέρβερ: **AX52 #2833256**, HEL1-DC8
- IP: **65.109.155.163**
- Χρήστης: **deploy**

Μαθήματα από τη μέρα που χάθηκε:

- Το Remote Console **λήγει** — ο χρόνος μετράει από τη σύνδεση, όχι από τη
  χρήση. Ζήτα το όταν μπορείς να κάτσεις αμέσως.
- Επαναλαμβανόμενες αποτυχίες SSH ενεργοποιούν **fail2ban** και μπλοκάρουν
  την IP σου. Άλλαξε δίκτυο ή περίμενε 15 λεπτά.
- **Rescue/Reset θέλει reboot** και ρίχνει το εργοστάσιο. Τελευταία επιλογή.
